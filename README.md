# Site Ndiaya Thiam – Salon de tresses (Guédiawaye)

Site vitrine statique (HTML + CSS + JS), prêt pour GitHub Pages.

## À vérifier / personnaliser
- `index.html` : les tarifs (en FCFA) sont des exemples à corriger, ainsi que « +500 coiffures », les horaires et les questions de la FAQ.
- Photos : mettez-les dans un dossier `images/`, puis dans `style.css` remplacez par exemple
  `.p1 { background-image: url("images/tresse1.jpg"); }`
- Ajoutez votre Instagram/Facebook dans la section Contact si vous en avez.

## Mettre en ligne (GitHub Pages)
1. Créez un dépôt public sur github.com (ex. `ndiaya-thiam`).
2. Envoyez-y `index.html`, `style.css`, `script.js` et `README.md` (« Add file » → « Upload files »).
3. **Settings → Pages** → Source : *Deploy from a branch*, branche `main`, dossier `/ (root)` → Save.
4. Après 1 à 2 minutes : `https://VOTRE-PSEUDO.github.io/ndiaya-thiam/`.
